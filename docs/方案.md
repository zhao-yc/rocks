# Rocks 首版方案

## 定位与范围

中国用户优先，免费、源码公开，以底部单手操作、简洁标签为主。首页不放应用广告、推广位或资讯流。Android 默认资源中文、英文系统使用英文资源，保留进一步国际化的空间。关于其他浏览器的主观评价不作为已证实的市场结论。

交互操作参考 iPhone Safari，UI 保留 Rocks 自己的苔绿、暖纸色与炭黑文字风格；主要功能优先落地为可编译、可安装的 Android 原生浏览器。

本轮交付可持续开发的工程与 Android 原型。鸿蒙建立原生结构，按真实 SDK 条件推进。许可证待项目所有者选择，源码公开不等于已授予开源使用许可。候选域名 browser.rocks 未购买，不配置 DNS。

## 架构与数据

- Android：Kotlin、Compose、系统 WebView，最低 Android 10。`core` 仅含导航与状态逻辑，平台适配层处理生命周期、文件、分享和下载。
- 鸿蒙：ArkTS、ArkUI、ArkWeb，Stage 模型，不使用 Android 兼容壳。初始 HarmonyOS 5 / API 12 配置待真实 DevEco 首次编译确认。
- 双端统一 JSON 字段、搜索引擎标识、书签历史和会话语义，分别实现 UI、引擎和存储。契约见 `shared/browser-data.schema.json` 与 fixture。
- Android 使用应用私有目录的 AtomicFile；鸿蒙用 Preferences 保存同一 JSON 载荷。未知版本或损坏内容保留原始数据，不静默覆盖。
- Android 会话读写上限为 4 MiB UTF-8 字节，读取过程中即检查上限并严格解码。恢复失败时本次运行只在内存中浏览，不覆盖原件；普通写入失败可由后续快照重试。此为 Android 存储边界，不改变共享 JSON v1 字段。

## 当前 Android 行为与边界

地址栏支持 HTTPS 默认补全、国际域名、搜索词编码。默认必应国内入口，可选百度、DuckDuckGo、Google。HTTP 地址允许访问且标示 HTTP；HTTPS 标识只说明 URL 协议，不代表站点可信。证书错误始终取消，无绕过入口。

普通标签最多 24 个。进程内切换保留各自导航栈；关闭当前项选择相邻项，关闭最后一个生成首页。重建只恢复 URL、选中标签、书签、历史和设置，不恢复表单、滚动和前后退栈。首页按钮清空当前标签的引擎导航栈。

Android 采用 Safari 风格的底部交互：地址栏平时显示协议与域名，点按后全选完整 URL；取消或点按页面遮罩放弃草稿，非法提交保留编辑内容，成功提交后关闭键盘。地址栏左划切换后一标签、右划切换前一标签，两端停留；编辑时不处理切换手势。分享、书签和标签总览可从底部直接打开，首页与设置放在更多菜单。

标签总览为全屏自适应卡片网格，标记当前标签并定位到其附近；卡片显示标题与域名，不采集网页截图。点按选择、关闭按钮与横划关闭、新建和完成均可操作，关闭最后一个仍生成首页。长按底部标签按钮提供新建、关闭当前、关闭其他操作。手势只作用于地址栏和标签卡片，不拦截网页横向滚动或系统边缘返回。此轮不新增 iOS 工程，鸿蒙的对应交互后续独立实现。

网页 HTTP(S) 链接长按菜单支持前台/后台标签打开、复制链接与系统分享；后台标签不切走当前页，选择后才加载。仅处理当前前台 WebView 的链接命中，不拦截普通文字长按选择，不将非网页协议送入新标签。前台/后台都遵守 24 标签上限。

历史最多 500 条、书签最多 200 条，按 URL 去重。普通标签共享 Cookie/网站存储，清空历史只删 URL 历史。Android 备份关闭，无遥测 SDK、无账号同步。

下载需确认，只支持 HTTP(S)，由系统 DownloadManager 保存至下载目录；不支持 blob/data 下载。上传使用系统文档选择器，只向网页交付选中的 content URI。分享和视频自定义全屏已实现，需真机验收。

网站相机、麦克风、定位在原型中明确拒绝并提示。外部应用仅开放前台、主框架、有手势并经确认的 tel/mailto/sms/geo。微信/支付宝等自定义协议、intent 链接与弹窗登录尚未开放。

## 后续顺序

1. Android CI、恢复与导航回归；国内网络真机验证站点、登录、下载与应用链接。
2. 经用户确认安装 DevEco/SDK 并接受许可，首次 HAP 编译；补齐鸿蒙多标签与恢复契约测试。
3. 双端来源级网站权限、可审计外链策略、弹窗登录、网站数据清理；低内存、进程终止和下载失败处理。
4. 可访问性、深色模式、国际化覆盖与签名分发。

网页广告过滤后置。无痕必须验证 Cookie、WebStorage、IndexedDB、Service Worker、缓存和进程会话隔离，仅关闭历史记录不合格。暂不做密码库、AI、桌面版或插件商店。
