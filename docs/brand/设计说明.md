# Rocks 品牌图标

标识采用「岩石切面 R」：圆润的岩体构成字母 R，顶部浅绿切面与向右下伸展的薄荷绿切面呼应岩石的层次和向前浏览的动势。内部窗口保持镂空，小尺寸下也能辨认轮廓。

深苔绿 `#173F35` 为图标底色，暖白 `#F3F5E7` 为主体，浅绿 `#B5D4B7` 与薄荷绿 `#80B99D` 为切面。沿用应用的苔绿、暖纸色视觉方向。图形不依赖字体、外部图片、阴影或渐变。

## 资源维护

`rocks.svg` 是唯一设计源，使用 72 × 72 画布和 18 单位圆角。修改后在仓库根目录执行：

```sh
node scripts/sync-brand-icons.mjs
node scripts/sync-brand-icons.mjs --check
```

同步脚本更新 Android Gecko 主线、原 WebView 回归工程和鸿蒙 SVG。Android 的 `ic_rocks` 保留完整底板版本，自适应桌面入口使用 `@mipmap/ic_rocks`：背景覆盖 108 × 108 画布，前景的关键轮廓位于中心直径 66 的安全圆内；圆形、圆角方形等裁切由系统启动器决定，不在前景再画底板。Android 13 及以上复用前景透明度轮廓生成系统主题图标。

CI 使用 `--check` 防止跨端资源不同步。新增或改变 SVG 元素类型时，应同步调整脚本的解析和 Android 转换逻辑。

图标资源更新不改变包名、签名或用户数据，也不代表已经发布新的安装包。设备桌面和鸿蒙编译仍需对应平台验收。
