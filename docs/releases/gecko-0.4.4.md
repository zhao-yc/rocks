# Rocks Gecko 0.4.4：修复网页生命周期闪退

Android 10+ / ARM64，版本 `0.4.4-gecko`，versionCode 8。沿用现有包名及固定签名，可直接覆盖安装。

- 修复打开网页、切换标签或恢复页面时可能发生的主线程闪退。GeckoView 在网页尚未附着或已经解绑时，会传入空显示连接；原 Kotlin 重写产生的非空检查错误地拒绝了这一正常调用。
- 显示连接跟踪改为保持 Gecko 的实际 Java 调用语义，成功释放后才清除引用；无效连接仍由引擎拒绝。
- 保留 0.4.3 的顶部安全区、背景衔接和滚动模糊效果，以及现有底部悬浮栏。
- 增加实际 Android/Gecko 显示连接生命周期回归包，覆盖未附着网页释放、解绑后的再次释放，以及过期连接拒绝。

建议覆盖安装后先检查冷启动和恢复标签，再打开百度、英纵，反复切换、滚动、回顶及横竖屏。模拟器验证与手机视觉验收分别记录，不能相互替代。
