# Rocks Gecko 0.4.5：顶部模糊透明渐变

Android 10+ / ARM64，版本 `0.4.5-gecko`，versionCode 9。沿用现有包名及固定签名，可直接覆盖安装。

- 按本轮确认的参考图2，增强网页在状态栏下方透出的模糊色彩，减少整块纯色遮罩感。
- 在顶部安全区下缘增加 18dp 的透明渐隐，模糊颜色逐渐消退到真实网页；回顶时消失，不改变网页尺寸或滚动位置。
- 渐隐层不接收触摸，网页顶部入口和菜单继续可点。复用原有局部采样和同一帧纹理，不增加网页脚本、桥、权限或采样次数。
- 保留 0.4.4 的网页显示连接释放修复，以及原有底部悬浮栏和手势。

建议覆盖安装后检查百度搜索框、蓝色按钮及新闻图片经过顶部时的模糊与渐隐，再检查英纵固定页头、菜单、回顶、旋转和后台返回。模拟器检查与手机视觉验收分别记录。
