# Gecko 0.4.7 顶部透明对照版

- 去掉顶部模糊纹理、渐隐覆盖层及其全部纹理读取、监听和计算；不只是隐藏画面。
- 状态栏透明，下面为网页白底或起始页浅色应用底色；网页始终避开顶部和两侧安全区。
- 去掉顶部效果专用的滚动状态与网页平移，保留底栏收放、引擎、TextureView 后端和刷新率策略。
- 版本为 0.4.7-gecko / versionCode 11，沿用包名与固定开发签名，可覆盖安装，不清除浏览数据。
- 请在同一手机、相同刷新率和同一网页中比较慢拖、快滑及惯性滚动。本版本用于定位，尚未证明滚动性能改善。
- 手机挖孔、系统图标、键盘、Dark Reader、全屏及真实滚动体验需要分别确认。
