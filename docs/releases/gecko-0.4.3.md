# Rocks Gecko 0.4.3：顶部安全区与滚动模糊

Android 10+ / ARM64，版本 `0.4.3-gecko`，versionCode 7。

沿用现有 Gecko 体验版的包名和固定签名，可以直接覆盖安装，不需要卸载；请在应用菜单中确认版本为 0.4.3。

本次更新：

- 网页放在实际状态栏和挖孔安全区下方，避免百度头像、英纵 Logo 和菜单与时间、电量、网络图标重叠。
- 顶部背景跟随网页页头主色，白色页面保持白色，深色页面使用相应底色；过滤 Logo、文字和照片干扰，并调整系统图标深浅。
- 加入只在顶部安全区内显示的滚动模糊过渡，回顶渐退，不改变网页视口和底部悬浮栏行为。
- 修正 `viewport-fit=cover` 页面重复避让，以及已加载标签切换时的顶部底色重绘。
- 原生局部采样只在内存处理，不保存、上传或记录画面，不新增网页脚本、原生 JavaScript 桥或权限。

发布前通过核心及应用单元测试、扩展脚本测试、lint、APK 编译和实际固定签名校验。手机视觉效果仍待本次真机测试，自动检查不代表已通过真机验收。

建议覆盖安装后测试：

1. 打开百度首页和 `https://www.yinzon.com/`，确认顶部入口、Logo、菜单完整可见且可点。
2. 缓慢上下滚动并回顶，检查顶部背景、模糊过渡与系统图标是否清楚，无残影或位置跳动。
3. 切换深浅色标签，打开/关闭 Dark Reader，并检查横屏、键盘、网站全屏及返回。

详细清单：[顶部浏览体验验收](https://github.com/zhao-yc/rocks/blob/main/docs/顶部浏览体验验收.md)。
