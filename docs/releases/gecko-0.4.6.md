# Rocks Gecko 0.4.6：网页真实下穿状态栏

Android 10+ / ARM64，版本 `0.4.6-gecko`，versionCode 10。沿用现有包名及固定签名，可直接覆盖安装。

- 网页视图使用完整窗口高度。首屏整体下移避让系统状态栏，滚动后逐渐移到窗口顶部，真实网页内容进入状态栏背后；回顶恢复避让。滚动不改变网页视口高度。
- 在真实网页上方合成同坐标的模糊与透明渐变遮罩，不再将一行或一条网页截图拉伸到状态栏；网页下穿后不再铺不透明底色。
- 左右挖孔、原生起始页、提示条继续避让。首屏平移时同步引擎屏幕坐标与底部裁切提示，保持点击与底部固定控件位置正确。
- 保留底部悬浮栏及手势，以及显示连接释放修复、采样失效隔离和每秒最多 15 次的限制。
- 新增真实 View 几何设备回归，检查首屏避让、滚动后进入状态栏、滚动前后视口高度一致、回顶恢复，避免仅验证截图视觉。

请覆盖安装后检查百度和英纵首屏、慢速滚动、回顶、固定页头及菜单，再检查横竖屏、键盘、后台返回和网站全屏。手机视觉与流畅度需单独确认。
