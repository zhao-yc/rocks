# 真机与站点验收清单

这是待执行清单，不代表已经通过。不绕过证书、不修改电脑安全设置，不把真实账号密码写入夹具。

## 基础行为

- Android 10 与较新真机：启动、底部安全区、键盘避让、系统返回、旋转和暂停恢复。
- 域名、中文域名、HTTP/HTTPS、搜索编码与非法协议；当前 URL 真实显示。
- 新建/切换/关闭当前、后台和最后一个标签；各标签导航栈独立。
- Safari 风格地址栏：点按全选完整 URL，清空、取消、点遮罩与系统返回；非法提交保留草稿，成功提交收起键盘；编辑时网页重定向不能覆盖草稿，切换标签不能沿用旧草稿。
- 地址栏左/右横划切换相邻标签；短拖动不触发，两端不循环、不隐式新建，网页自身的滚动和系统返回手势正常。
- 全屏标签网格：当前卡片标记、滚动定位、点按切换、短拖回弹、横划/按钮关闭、关闭最后一个、新建与完成；长按标签按钮的三项快捷操作。
- 中文/英文、窄屏/横屏、大字体与 TalkBack：按钮可触达，卡片关闭有替代入口，完整 URL 可读；分享/书签直达，更多菜单的首页/历史/设置可用。
- 杀进程恢复 URL、活动标签、书签历史、搜索设置；不声称恢复表单或完整导航栈。
- 损坏/未来版本文件保留；低存储写入失败提示。
- 超过 4 MiB、非法 UTF-8 和不可读会话提示恢复失败；后续浏览不覆盖原件。恰好 4 MiB 的合法文件仍可恢复。
- AtomicFile 写入中断后恢复上次提交的数据；仅剩旧版 `.bak` 时仍可恢复。对应设备测试见 `AtomicSessionFileTest`，尚待执行。

## 安全与鸿蒙

- SSL 测试站的过期、自签和域名不匹配证书均取消，没有继续按钮。
- 阻止 HTTPS 页的 HTTP 混合内容、自动弹窗、无手势外部应用跳转。
- 网站设备权限明确拒绝，不静默授予或遗留未处理请求。
- 普通标签共享 Cookie，清空历史不声称清空所有网站数据。
- Android 12+ 按显式规则排除私有浏览数据的云备份和设备迁移，仍需在目标厂商系统验证迁移工具行为。
- API 29 模拟器冒烟不等价于国内真机网络、登录或下载验收。
- DevEco 导入 `harmony`，核对版本后编译未签名 HAP；由用户配置本机签名，上手机验证 ArkWeb 与会话适配。ArkTS 文本检查不能当作 SDK 编译成功。
