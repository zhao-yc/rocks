# Safari 风格顶部体验验收（2026-10-31）

## 本次改动

- Android Gecko 主线统一保留实际状态栏、挖孔和横屏安全边距；网页、起始页及错误/进度提示共用顶部位置。网站全屏时释放，退出时恢复。
- 宿主已消费的顶部和左右安全边距不再通过 Gecko CSS `env()` 重复提供，避免 `viewport-fit=cover` 页面出现双重留白。底部网站安全边距和现有浮栏遮挡提示保持原有语义。
- 使用网页顶部窄条主背景衔接状态栏，过滤少量 Logo 和文字。未取得新文档有效画面前为白色，起始页使用 Rocks 底色；采样失败或照片颜色分散时保留当前有效颜色。
- 滚动 0～24 CSS 像素渐进显现原生模糊延展，仅绘制在状态栏安全区内，回顶渐退，不改变网页视口或拦截触摸。
- 直接读取 Gecko TextureView 的 Surface，避免把模糊层采回自身。采样与后台模糊共用唯一在途名额，间隔至少 67ms，无静止轮询；页面/文档、前后台、几何尺寸、Surface 和 View 身份均校验。采集位图立即回收，显示帧只保留当前内存引用，不落盘、记录或上传。
- 不修改底部悬浮栏，不添加网站脚本、原生 JavaScript 桥、权限或数据契约。实现阶段未公开发布；随后经用户明确授权，已发布 0.4.3 真机测试版，见下文。

## 真机必验清单（尚未执行）

1. **百度首页**：头像及右上入口位于系统图标下方，完整可点；状态栏背景与白色页头衔接，时间、电量和网络清楚。
2. **英纵首页**：Logo 与菜单整体位于状态栏下方；状态栏为白色，不被深绿色横幅染色；点开/关闭网站菜单后无重复留白。
3. **滚动**：长页缓慢上下滚动并回顶；检查固定页头、非固定页头、照片与文字进入顶部时的颜色和模糊变化。没有反复叠加、残影、黑边或网页位置跳动。
4. **页面与生命周期**：快速切换白色/深色标签、同网址重载、前后退、旋转、后台返回、锁屏返回；旧页面纹理不得污染当前页面。
5. **网页安全区**：分别验证默认 viewport、`viewport-fit=cover`、顶部使用 `padding-top: env(safe-area-inset-top)` 的页面；顶部只避让一次。横屏左右挖孔仍避让，底部固定控件不回归。
6. **原有交互**：Dark Reader 开关、网页输入框及键盘、地址编辑、查找、标签总览、扩展面板、底栏展开/收起和横向切标签。控件无遮挡，底栏与键盘行为保持正常。
7. **网站全屏**：视频等内容进入真正全屏时隐藏系统栏及顶部层，退出后安全区、颜色和系统图标正确恢复。
