## Android CI

首次 CI 在 SDK 初始化失败：第三方 action 尝试安装已不存在的 `tools` 包，尚未编译项目。该 action 默认在 GitHub 临时 runner 执行了 SDK 许可自动接受。本机没有接受许可或安装 SDK；已移除该 action，改为只核对并使用 runner 预装 SDK。模拟器需要额外系统镜像，现改为显式手动选项，未经许可确认不运行。

第二轮进入实际编译，发现跨 `core` 模块可空属性不能智能转换为 String；已改用局部不可变变量。CI 拆分为单元测试、lint、APK 三步，并编译 AndroidTest APK。
