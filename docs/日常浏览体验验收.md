# Android Gecko 日常浏览体验验收

本轮改进只作用于 Android Gecko 主线，以并行工作已合入的 0.4.7 固定顶部安全区为基础，沿用数据格式、包名和签名配置。本任务未公开发布新版本。

## 行为与边界

- 点开地址栏全选网址并显示最近访问；修改文字后按已打开标签、书签、历史的顺序检索标题和网址，去重后最多显示 6 条。匹配到已打开网页时切换标签，不额外打开重复页。检索只使用本机记录。
- 清空输入后显示最近访问；非法提交保留草稿并显示具体错误。取消、返回、点击面板外区域退出编辑；成功提交或切换标签后收起键盘。
- 标签按钮支持长按快捷菜单；新建标签后直接输入网址。总览定位当前标签，提供选中语义和窗口内撤销入口。
- 最近关闭保留 10 个用户主动关闭的普通网页，按最近关闭优先恢复网址、标题、原位置及桌面模式。只在本次运行内保留，进程结束即清空，不恢复表单、滚动位置或前后退栈。
- 只替换关闭最后一页时自动生成、尚未导航的唯一首页。达到 24 个标签时保留已有页面和恢复记录。批量、网站及扩展自行关闭、原生首页和扩展页不进入恢复记录；关闭其他标签先确认。
- 书签与历史分别搜索，保留原顺序；空列表和无匹配结果分别提示。清空历史的确认说明覆盖全部记录，包括筛选隐藏的记录，不清除 Cookie、网站存储、标签或下载。
- 加载时提供停止，主动停止不显示失败、不新增成功访问记录；真实网络、证书或内核错误继续显示失败。

## 自动化检查

新增策略测试覆盖匹配优先级、归一化去重、中文与网址检索、最近访问顺序与数量、删除后的更新、不同输入错误、编码后长度限制、恢复顺序与容量、上限不消费记录、过期撤销、自动首页识别以及停止/失败状态。

```text
node --test scripts/test-gecko-extension.mjs
node scripts/sync-brand-icons.mjs --check
gradle -p android/gecko-demo :core:test testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

原生测试 runner 增加了显式的 `daily_actions_url` 模式，仅允许硬件标识为模拟器且夹具为 `http://127.0.0.1:8878/`。它会整理专用模拟器中的测试标签，不能在用户手机或日常模拟器上运行。先启动提供 `/one`、`/two`、`/slow`、`/fail` 的本机夹具并映射端口，再执行：

```text
adb -s <专用模拟器序列号> reverse tcp:8878 tcp:8878
adb -s <专用模拟器序列号> shell am instrument -w -r -e daily_actions_url http://127.0.0.1:8878/ org.rocks.browser.geckodemo.test/org.rocks.geckodemo.DisplayLifecycleInstrumentation
```

它验证真实 Gecko 的末页初始化后恢复、桌面模式、程序关闭排除、24 标签上限不消费记录、停止及后续导航、失败网址保留，以及 Compose 的非法输入草稿、具体错误、新建自动聚焦和匹配标签切换。使用标准 Android 无障碍文本动作提交精确输入，避免测试被输入法的全角标点和拼音组合干扰；产品没有新增调试桥。

## 设备验收步骤

1. 打开两个不同网页并添加一个书签。点开地址栏检查全选、最近访问，输入标题和域名，选择“切换标签”检查标签数不变。清空、取消、返回和点击外部均不能触发导航。
2. 输入空白、非法端口、非网页协议及过长搜索词，检查草稿和具体错误；提交正常网址或搜索词应收起键盘。检查新建标签自动聚焦与横屏键盘布局。
3. 在总览连续关闭和撤销，核对网址、顺序、选中状态；长按标签按钮关闭后，从主界面撤销提示恢复。关闭最后一个网页再恢复，不应多留一个自动首页。
4. 更改桌面模式后关闭并恢复，核对首次请求的模式；打开到上限后尝试恢复，关闭一页再恢复，检查恢复记录未丢失。取消“关闭其他”不改变标签，确认后只保留当前标签且不污染单页误关记录。
5. 分别检索书签和历史，删除匹配书签、清空搜索、搜索无结果；历史筛选后清空全部历史，核对确认文本与清空后建议列表。仅在测试数据中执行清空步骤。
6. 用慢速页面点击停止，检查按钮恢复、没有错误条；再访问正常页和真实失败地址，核对取消标记不会影响后续导航或掩盖错误。
7. 检查大字体、无障碍操作标签和 TalkBack；回归地址栏横划、页面内查找、固定顶部安全区、横竖屏、后台返回及 Gecko 显示连接释放。
