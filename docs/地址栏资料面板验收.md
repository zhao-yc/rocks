# 地址栏资料面板验收

本轮实现概览、书签、历史三页的原生全屏覆盖层。点地址栏全选并弹出键盘；主动切分类收起键盘并保留草稿；一次系统返回或关闭按钮退出。书签与收藏共用数据，历史按本地日期分组，最近关闭仍只在本次运行有效。共享数据格式、包名和签名不变。

图标通过固定 Gecko 版本匿名请求和本地解码，页面 HTML 仅用于提取图标地址。并发 2，单次 5 秒，资源各限 256 KiB，最多 3 次重定向且禁止 HTTPS 降级。内存 4 MiB、磁盘 10 MiB，成功 7 天、失败 30 分钟；错误回退首字图块。没有第三方图标服务、扩展权限变更或新增网页通信桥。

5 秒约束的是应用等待时间。Gecko 158 的请求在响应头到达前不保证取消成功，此类请求继续占用全进程网络名额；迟到响应会关闭并释放名额，不交给已移除的图块。没有通过提前释放名额掩盖实际网络并发，也没有改变全局网络超时或证书策略。

本轮期间已同步主线的底栏背景功能及其所有者授权的专用通道例外。资料面板打开时暂停底栏背景检测，退出后按现有机制恢复；未恢复顶部纹理采样或模糊。

## 验收重点

原生资料面板测试需要专用 API 35 模拟器及显式的 `node scripts/gecko-ux-fixture.mjs --icons`，同时反向映射 8878、8879 两个回环端口，再向既有 runner 传入 `-e address_hub_url http://127.0.0.1:8878/`。该模式会整理测试标签和书签，不能运行在用户手机或日常设备中。普通日常回归仍使用 `daily_actions_url`，顶部回归仍使用 `safe_area_url`，无参数运行显示连接的三项检查。

- 三分类、收藏与最近关闭、指定记录恢复、上限与清空、书签删除后即时更新、历史分组和搜索。
- 首次全选与键盘、主动分类隐藏键盘、草稿和光标保留、搜索焦点互斥、一次返回、旋转与滚动位置。
- 图标 PNG/ICO、相对路径、标准回退、重定向、超时、超限、损坏、缓存和迟到结果。
- 覆盖层不重新创建 GeckoView，键盘不改变其视口；顶部安全区与显示连接生命周期继续回归。
